# Portfolio

Kathryn Collins, Senior Manager of Content Operations at BigPanda. I lead documentation programs and edit the standards behind them, for human readers and for the AI models that now read and draft docs too. [About me, experience and LinkedIn](about.md).

## Reading paths

### [Documentation leadership](docs-lead/)
Owning a docs program end to end: information architecture, docs as code, docs written for AI readers, measurement, and the automation behind it, held to human review.

### [Technical editing](technical-editor/)
Review systems for AI-assisted publishing: editorial standards a model can apply, checks a person can trust, and a pre-registered test of five models against one style standard.

The paths share the same piece pages and differ in order and framing. Internal names, identifiers and figures are removed or generalized throughout; bracketed items are open questions or figures still to be confirmed.

## Structure

- `case-studies/`: longer write-ups.
- `samples/`: work samples.
- `talks/`: talk materials.
- `test-kit/`: the test kit the case study and talk are built on.
- `projects/<project-name>/`: one page per project.
- `docs-lead/`, `technical-editor/`: reading paths. Each piece page is shared; a path page only orders and frames them.

## Contributing notes

- Keep entries brief and outcome-focused.
- Don't include confidential, customer, or internal-only material. Redact or summarize instead.
