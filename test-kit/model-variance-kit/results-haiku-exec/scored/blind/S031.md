# S031

## Original

You can create maintenance plans to suppress alerts during planned work. You'll see the plan appear in the list once you save it, and you can stop it early if you need to. You need Admin permissions to create or edit a maintenance plan. You may want to notify your team before you start a plan.


## Rewrite

# Maintenance plans

You can create maintenance plans to suppress alerts during planned work. The plan appears in the list after it is saved. To end a plan early, stop it from the list. Creating or editing a maintenance plan requires Admin permissions. Notify your team before a plan starts.
