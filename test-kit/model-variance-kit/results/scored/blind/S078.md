# S078

## Original

To add an environment:

1. You open the **Environments** page.
2. Then you click **New Environment**.
3. You should enter a name and a filter condition.
4. You click **Save** — the environment appears in the list within a few seconds.


## Rewrite

To add an environment:

1. Open the **Environments** page.
2. Click **New Environment**.
3. Enter a name and a filter condition.
4. Click **Save**. The environment appears in the list within a few seconds.
