# S010

## Original

Correlation patterns group related alerts into a single incident. Changes to a pattern apply to new alerts only — existing incidents keep their current grouping until they resolve. You can edit a pattern at any time from the **Correlation** page.


## Rewrite

Correlation patterns group related alerts into a single incident. Changes to a pattern apply only to new alerts. Existing incidents keep their current grouping until they resolve. To edit a pattern, open the **Correlation** page and select the pattern you want to change.
