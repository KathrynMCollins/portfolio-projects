## Rewrite

## Send a test alert

Run the following command to send a test alert:

```bash
curl -X POST https://api.example.com/v1/alerts \
  -H "Authorization: Bearer <your_api_key>" \
  -d '{"status": "critical", "host": "db-01"}'
```

Replace `<your_api_key>` with your API key.

The alert can take up to 30 seconds to appear. This delay is expected.
