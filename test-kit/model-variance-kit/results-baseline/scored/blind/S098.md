## Original

If the sync fails, check the integration logs. The most common cause is an expired token. Generate a new token and paste it into the **Token** field. The sync resumes on its own; there is no need to restart the integration. If only one environment is affected, just re-run the sync for that environment.


## Rewrite

## Troubleshooting a failed sync

If a sync fails, check the integration logs. The most common cause is an expired token.

To resolve an expired token:

1. Generate a new token.
2. Paste the new token into the **Token** field.

The sync resumes automatically. You do not need to restart the integration.

If the failure affects only one environment, re-run the sync for that environment.
