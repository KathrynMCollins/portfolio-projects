## Rewrite

## Troubleshooting sync failures

If a sync fails, check the integration logs to identify the cause.

### Expired token

An expired token is the most common cause of sync failures. To resolve it:

1. Generate a new token.
2. Paste the new token into the **Token** field.

The sync resumes automatically. You don't need to restart the integration.

### Single environment affected

If the failure affects only one environment, re-run the sync for that environment.
