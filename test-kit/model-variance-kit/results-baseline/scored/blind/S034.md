## Original

The Harness integration sends deployment events to the platform. Use it to leverage change data in root cause analysis and to seamlessly connect deployments to the incidents they cause.


## Rewrite

# Harness Integration

The Harness integration forwards deployment events from Harness to the platform. Use this integration to:

- Include deployment change data in root cause analysis.
- Correlate deployments with the incidents they trigger.
