# S022

## Original

You can create maintenance plans to suppress alerts during planned work. You'll see the plan appear in the list once you save it, and you can stop it early if you need to. You need Admin permissions to create or edit a maintenance plan. You may want to notify your team before you start a plan.


## Rewrite

## Maintenance plans

Use maintenance plans to suppress alerts during planned work.

**Required permissions:** Admin

**Before you begin:** Consider notifying your team before you start a maintenance plan.

### Create a maintenance plan

1. Create the maintenance plan.
2. Save the plan.

The plan appears in the maintenance plan list after you save it.

### Stop a maintenance plan early

You can stop an active maintenance plan before its scheduled end time.
