# S069

## Original

You can create maintenance plans to suppress alerts during planned work. You'll see the plan appear in the list once you save it, and you can stop it early if you need to. You need Admin permissions to create or edit a maintenance plan. You may want to notify your team before you start a plan.


## Rewrite

# Creating and Managing Maintenance Plans

You can create a maintenance plan to suppress alerts during planned work. After you save the plan, it appears in the list of maintenance plans. If needed, you can stop a plan before its scheduled end.

To create or edit a maintenance plan, you must have Admin permissions. Before you start a plan, notify your team.
