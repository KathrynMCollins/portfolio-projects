# S146

## Original

You can create maintenance plans to suppress alerts during planned work. You'll see the plan appear in the list once you save it, and you can stop it early if you need to. You need Admin permissions to create or edit a maintenance plan. You may want to notify your team before you start a plan.


## Rewrite

## Create a maintenance plan

Use a maintenance plan to suppress alerts during planned work. After you save a plan, it appears in the maintenance plan list. To end a plan before its scheduled end time, stop it from the list.

**Prerequisite:** You must have Admin permissions to create or edit a maintenance plan.

**Tip:** Notify your team before you start a maintenance plan so that they know alerts are suppressed.
