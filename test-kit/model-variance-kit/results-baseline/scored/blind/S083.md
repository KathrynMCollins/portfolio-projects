## Rewrite

## Sending a Test Alert

Use the following command to send a test alert:

> **Note:** Confirm the default port with engineering before publishing.

```bash
curl -X POST https://api.example.com/v1/alerts \
  -H "Authorization: Bearer <your_api_key>" \
  -d '{"status": "critical", "host": "db-01"}'
```

### Parameters

- `Authorization`: Bearer token containing your API key.
- `status`: Severity of the alert (for example, `critical`).
- `host`: Identifier of the host generating the alert.

### Expected Behavior

Alerts may take up to 30 seconds to appear after the request is sent. This delay is expected.
