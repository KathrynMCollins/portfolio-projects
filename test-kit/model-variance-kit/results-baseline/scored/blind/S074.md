# S074

## Original

You can create maintenance plans to suppress alerts during planned work. You'll see the plan appear in the list once you save it, and you can stop it early if you need to. You need Admin permissions to create or edit a maintenance plan. You may want to notify your team before you start a plan.


## Rewrite

# Create a maintenance plan

Use a maintenance plan to suppress alerts during planned work.

## Prerequisites

- You must have Admin permissions to create or edit a maintenance plan.
- (Recommended) Notify your team before you start a plan.

## Behavior

- After you save a maintenance plan, it appears in the maintenance plan list.
- You can stop an active plan before its scheduled end time.
