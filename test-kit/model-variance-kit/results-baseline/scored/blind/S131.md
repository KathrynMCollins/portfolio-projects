## Original

## Rewrite

# Correlation Patterns

Correlation patterns group related alerts into a single incident.

## Behavior of pattern changes

Changes to a correlation pattern apply only to new alerts. Existing incidents retain their current grouping until they resolve.

## Editing a pattern

You can edit a correlation pattern at any time from the **Correlation** page.
