## Rewrite

# Troubleshooting a Failed Sync

If a sync fails, follow these steps:

1. **Check the integration logs** to identify the cause of the failure.
2. **Verify the token.** An expired token is the most common cause of failure.

## Resolving an Expired Token

1. Generate a new token.
2. Paste the new token into the **Token** field.

The sync resumes automatically. You do not need to restart the integration.

## Single-Environment Failures

If only one environment is affected, re-run the sync for that environment only.
