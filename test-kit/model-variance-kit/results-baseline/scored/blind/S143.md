## Original

Send a test alert with the command below. [VERIFY: confirm the default port with engineering]

```bash
curl -X POST https://api.example.com/v1/alerts -H "Authorization: Bearer <your_api_key>" -d '{"status": "critical", "host": "db-01"}'
```

It's important to note that the alert can take up to 30 seconds to appear — this is expected.


## Rewrite

## Send a test alert

Send a test alert with the following command. Replace `<your_api_key>` with your API key.

```bash
curl -X POST https://api.example.com/v1/alerts \
  -H "Authorization: Bearer <your_api_key>" \
  -d '{"status": "critical", "host": "db-01"}'
```

[VERIFY: confirm the default port with engineering]

Alerts can take up to 30 seconds to appear. This delay is expected.
