## Rewrite

# Troubleshooting Sync Failures

If a sync fails, review the integration logs to identify the cause.

## Common Cause: Expired Token

An expired token is the most frequent cause of sync failures. To resolve:

1. Generate a new token.
2. Paste the new token into the **Token** field.

The sync resumes automatically. You do not need to restart the integration.

## Single-Environment Failures

If the failure affects only one environment, re-run the sync for that environment.
