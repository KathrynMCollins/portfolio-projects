## Rewrite

## Troubleshooting a failed sync

If a sync fails, check the integration logs to identify the cause.

### Expired token

An expired token is the most common cause of sync failures. To resolve it:

1. Generate a new token.
2. Paste the new token into the **Token** field.

The sync resumes automatically. You do not need to restart the integration.

### Single-environment failures

If the failure affects only one environment, re-run the sync for that environment only.
