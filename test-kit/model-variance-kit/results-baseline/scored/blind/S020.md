# S020

## Original

Correlation patterns group related alerts into a single incident. Changes to a pattern apply to new alerts only — existing incidents keep their current grouping until they resolve. You can edit a pattern at any time from the **Correlation** page.


## Rewrite

# Correlation Patterns

Correlation patterns group related alerts into a single incident.

- **Scope of changes:** Edits to a pattern apply only to new alerts. Existing incidents retain their current grouping until they resolve.
- **Editing:** You can edit a pattern at any time from the **Correlation** page.
